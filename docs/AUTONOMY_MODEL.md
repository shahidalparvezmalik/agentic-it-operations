# Autonomy Model

AgenticOps uses five conceptual autonomy levels.

| Level | Capability | Control |
|---|---|---|
| L0 | Observe | Read-only |
| L1 | Recommend | Human review |
| L2 | Approved Action | Explicit approval |
| L3 | Controlled Autonomous | Policy allow-list + low risk |
| L4 | Restricted | Human authorization for high-impact work |

The MVP concentrates on L1 and L2.

## Why this matters

The value of agentic operations is not measured only by how much work an agent can perform. A credible operating model must also define:

- what the agent may do,
- under what conditions,
- with what confidence,
- within what risk boundary,
- and who remains accountable.

## Portfolio Positioning

This model extends the earlier AI-assisted service-desk project from recommendation to a broader IT Operations decision loop.
